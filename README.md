# Gefrem Engineering — Company Website

A professional company website built for **Gefrem Engineering**, a construction and engineering firm based in Addis Ababa, Ethiopia. 
The site presents the company's brand, services, and expertise with a clean, modern design system.

## ✨ Features

- **Responsive design** — fully optimized for mobile, tablet, and desktop
- **Hero section** — bold headline with brand tagline and CTA
- **About section** — company story, mission, and values
- **Services section** — detailed breakdown of engineering services offered
- **Brand design system** — consistent orange (`#EE6123`) and charcoal color palette with Syne / DM Sans typography
- **Smooth scroll navigation** — seamless section-to-section UX
- **Clean component architecture** — modular, reusable React components

## 🚀 Getting Started

### Prerequisites

- Node.js v18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/smile679/gefrem_Engineering.git

# Navigate into the project directory
cd gefrem_Engineering

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
